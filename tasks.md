excudra is a Claude Code plugin plus a task runner, in this repository. guard.py holds the hooks (pre, stop, recall), wired in hooks/hooks.json. run.py is the autonomous runner: a worker `claude -p` session builds each task, a separate verifier session checks it, and the loop retries with feedback.
Constraints: Python standard library only, no new dependencies, no new frameworks. Tests are plain assert scripts run as `python test_run.py` / `python test_guard.py` (no pytest). Keep diffs small and code readable. Do not edit LICENSE, README.md or this tasks.md. Claude Code is the only supported agent.
